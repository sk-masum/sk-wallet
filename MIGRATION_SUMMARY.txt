================================================================================
                           MIGRATION PATTERNS
================================================================================

QUERY OPERATIONS:

Before (Prisma):
  const user = await prisma.user.findUnique({ where: { email } })
  const cards = await prisma.card.findMany({ where: { owner_id } })
  const result = await prisma.card.create({ data: {...} })
  await prisma.card.update({ where: { id }, data: {...} })
  await prisma.card.delete({ where: { id } })

After (Drizzle):
  const user = await db.select().from(User).where(eq(User.email, email)).get()
  const cards = await db.select().from(card).where(eq(card.owner_id, userId))
  const result = await db.insert(card).values({...}).returning()
  await db.update(card).set({...}).where(eq(card.id, id))
  await db.delete(card).where(eq(card.id, id))

CONTEXT TYPE CHANGES:

Before:
  { userId: string; prisma: ReturnType<typeof getRequiredPrismaClient> }

After:
  { userId: string; db: Db }

ERROR HANDLING:

Before:
  if (error instanceof Prisma.PrismaClientKnownRequestError) {
    console.error(error.code, error.meta)
  }

After:
  if (error instanceof Error) {
    console.error(error.message)
  }

================================================================================
                         TROUBLESHOOTING
================================================================================

If you encounter issues:

1. TypeScript Errors:
   $ npm run db:generate  # Regenerate types

2. Database Connection Issues:
   - Check NEXT_PUBLIC_DATABASE_URL environment variable
   - For Turso: format is libsql://your-db.turso.io
   - For local: format is file:./dev.db

3. Import Errors:
   - Check imports use @/db/schema for tables
   - Check imports use @/db/client for database

4. Query Errors:
   - Ensure table names match schema definition
   - Verify column names are correct
   - Check eq(), and(), or() operators from drizzle-orm

For detailed help, see MIGRATION_GUIDE.md
